Shogun AI — Game Auto-Play

A Python program that plays Shogun Showdown on its own

Built with Claude. This was a project I worked on with Claude's help — I directed what to build and tried to understand it, but Claude wrote and debugged most of the Python.

A Python program I made to automatically play Shogun Showdown, a turn-based game I like. It takes a screenshot, uses OpenCV to figure out the game state (my health, enemy positions, what skills are ready), then picks a move and presses the keys. I can run the decisions three ways: a hand-written rule engine (the default), a local language model through Ollama, or the Claude API.

What's actually in it

  • Screen capture and OpenCV parsing of the game state
  • A rule engine (600+ lines) that decides what to do
  • Optional Ollama / Claude API backends for decisions
  • A "playbook" that remembers tactics that worked
  • Stuck detection and auto-restart on death

What I wanted vs. what actually happened

Reading the game state with computer vision is the hard part, and it's still not fully reliable — it works on the screens I tested, but I haven't covered the whole game. The rule engine can play, but it's not smarter than a careful human. I built this mostly to understand how computer vision and decision-making fit together, and it did teach me that.
