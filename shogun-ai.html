It captures the screen, parses the game state with OpenCV, and picks a move — either through a hand-written rule engine or a local LLM. Screenshot → CV Parse → Decide → Execute → Loop.

📸 Screen Capture & CV Parsing
  • mss for fast capture, pygetwindow to find the game window; background mode (no focus stealing)
  • OpenCV parses HP, position, facing, enemy intent, skill cooldowns, damage, queue, items, and menu/victory states
🧭 Decision Engine (3 backends)

Rule engine (default): 614 prioritized rules — queue release, threat response, lethal-combo search, positioning. Free and instant.

Ollama LLM: game state → structured text → JSON action, with auto-fallback across models.

Claude API: vision for screen analysis + text for tactical decisions.

📖 Playbook System
  • Records successful tactics (scene fingerprint + actions + score) and replays them in similar situations
  • Used as few-shot examples to guide the LLM, or replayed directly with the best score
🔁 Smart Recovery
  • Stuck detection over 3 turns, auto-restart on death, non-combat screen handling
  • Action validation, deterministic cooldown tracking, background mode
⚖️ Scoring System
  • Damage +5/dmg, kill +10, damage taken −30/hp, miss penalty, idle penalty
