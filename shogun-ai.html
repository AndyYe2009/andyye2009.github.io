Overview

Shogun AI is a Python-based fully automatic game-playing agent for Shogun Showdown — a turn-based tactical roguelike. The AI captures the game screen, analyzes the game state using OpenCV computer vision, makes tactical decisions through a multi-layer rule engine (or local LLM), and executes keyboard actions to play the game.

Pipeline

Screenshot → CV Parse → Decision → Execute → Loop

1. Screen Capture

Uses mss for fast screen capture and pygetwindow to locate the Shogun Showdown game window. Supports background mode (no focus stealing) via Windows API key injection and configurable crop regions for borderless window setups.

2. Computer Vision Parsing

The screen parser uses OpenCV to analyze pixel data without relying on AI vision models — making it fast, deterministic, and free. It detects:

  • Player HP, position, facing direction, character class
  • Enemy positions, HP bars, and next-turn intent indicators
  • Skill tile states: cooldown (gray saturation analysis), damage values, range
  • Attack queue count and queued skill indices
  • Consumable items and counts
  • Game state transitions: main menu, shop, victory, defeat

3. Decision Engine

Rule Engine (Default)

A 614-line prioritized decision system that doesn't require any AI model. Runs instantly with zero API cost.

  • Priority 1 — Queue Full: Release all skills immediately
  • Priority 2 — Has Queued Skills: Release or continue combo if lethal opportunity exists
  • Priority 3 — Threat Response: If enemy is about to attack → find lethal combo → if impossible, swap/dodge → otherwise hit with best skill
  • Priority 4 — Positioning: Move toward enemies, turn around, or wait for cooldowns
  • Lethal combo calculator: Exhaustively searches 1/2/3-skill combinations to find minimal overkill
  • AOE bias: Prefers melee AOE when enemies are adjacent (conserves ranged cooldowns)

Ollama LLM Backend

Uses a local language model (via Ollama) for decision-making. The game state is converted to structured text, and the LLM returns JSON actions. Features:

  • Supports any Ollama model (minicpm-v, llava, etc.)
  • Auto-fallback: tries configured model, then fallback models in order
  • Structured JSON output with validation

Claude API Backend

Optional integration with Anthropic's Claude API for the best decision quality. Uses the vision API for screen analysis and text API for tactical decisions.

4. Action Execution

Uses pydirectinput for fast, DirectInput-level keyboard simulation. Supports:

  • Movement: A/D keys (left/right on grid)
  • Turn: W key (flip character facing)
  • Skill cursor: Left/Right arrow keys to navigate skill bar
  • Queue: Enter key to add skill to attack queue
  • Release: Space key to execute queued skills
  • Consumables: Q/E keys
  • Wait: S key (skip turn)

Playbook System

A learning system that records successful tactical decisions and replays them in similar situations. Each entry stores:

  • Fingerprint: compressed scene signature (enemy count, ready skills, HP%)
  • Actions: the sequence of moves that worked
  • Score delta: how effective the play was
  • Reasoning: why the AI chose this action

When encountering a similar situation, the AI retrieves matching playbook entries and uses them as few-shot examples to guide the LLM decision (or directly replays them with the best score).

Smart Recovery Systems

  • Stuck detection: Tracks HP, enemy count, and position over 3 turns — if unchanged, auto-recovers
  • Auto-restart on death: Detects defeat screen, holds W to restart, confirms with Space/Enter
  • Non-combat screen handling: Recognizes main menu, character select, shop — presses Space to advance
  • Action validation: Pre-execution checks prevent impossible actions (e.g., queuing when full, releasing when empty)
  • Cooldown tracking: Deterministic tracker overrides CV mis-reads to prevent using skills on cooldown
  • Background mode: Plays without stealing window focus — user can use the computer while AI runs

Configurable Features

  • Multi-backend: Rule engine (free, fast) / Ollama (local LLM) / Claude API (best quality)
  • Skill scanning: Optional vision-model skill bar identification
  • Quiet mode: Minimal console output for long training runs
  • Playbook management: View stats, clear history, or replay top strategies
  • Environment config: All settings via .env file or environment variables

Scoring System

  • Damage dealt: +5/dmg
  • Enemy killed: +10/kill
  • Damage taken: -30/hp
  • Skill miss penalty: penalty for skills that don't connect
  • Action bonus: rewards using skills instead of idling
  • Idle penalty: small penalty for wait turns without reason
