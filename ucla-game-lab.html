UCLA Game Lab Summer Program

An intensive game development experience — exploring game design, interactive media, and creative coding

Overview

In July 2025, I attended the UCLA Game Lab Summer Program, an intensive game development experience at one of the world's leading game design programs. I explored game design principles, interactive media, and creative coding — working hands-on to create multiple game prototypes.

Projects

Card Game Prototype

As part of a team, I designed and playtested a physical card game from scratch. We focused on creating balanced mechanics, strategic depth, and an engaging player experience. This project taught me the fundamentals of game design iteration — prototyping, testing, gathering feedback, and refining the rules until the game felt right.

3D Game Project

I explored the fundamentals of 3D game development — building an interactive experience from concept to playable prototype. This involved environment design, 3D mechanics, and learning how to think spatially in a game engine. The project challenged me to consider perspective, scale, and player navigation in a three-dimensional space.

2D Game Project

I designed and developed a 2D game from scratch, applying principles of sprite animation, collision detection, and level design. This project gave me hands-on experience with the full game development cycle — from initial concept and paper sketches to a working digital prototype with responsive controls and interactive gameplay.
